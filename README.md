# html-css-project

A responsive web page built with **HTML5** and **CSS3** as part of my web development training.

🔗 **Live demo:** [https://endearing-sorbet-3e227a.netlify.app](https://endearing-sorbet-3e227a.netlify.app)

![Project preview](images/cover.png)

## About the project

This project is the first part of a web development formation I am following to strengthen my front-end skills. It focuses on building a clean, well-structured page from scratch using only HTML and CSS, without any framework.

## Features

- Semantic HTML5 structure
- Custom styling with a single CSS stylesheet
- Clean layout with sections (cover, about, services)
- Optimized images and SVG logo
- Deployed online with Netlify

## Technologies

- HTML5
- CSS3
- Git & GitHub
- Netlify (deployment)

## Project structure

```
html-css-project/
├── index.html
├── style.css
└── images/
    ├── about.png
    ├── cover.png
    ├── logo.svg
    ├── s1.png
    └── s3.png
```

## Run it locally

1. Clone the repository:
   ```bash
   git clone https://github.com/mouadh12-code/html-css-project.git
   ```
2. Open the folder and double-click `index.html` to view it in your browser.

## What I learned

- Structuring a page with semantic HTML
- Styling and layout with CSS
- Organizing a project (assets, stylesheet, folders)
